# Petunjuk Website Minimarket — Minimarket Kita

Paket ini berisi enam dokumen yang disesuaikan untuk pengembangan website minimarket.

## Urutan membaca
1. `prd.md` — kebutuhan produk dan fitur.
2. `tech_stack.md` — teknologi.
3. `arsitektur.md` — struktur berkas dan alur data.
4. `ui.ux.md` — rancangan tampilan dan pengalaman pengguna.
5. `instruction.md` — langkah implementasi dan deployment.
6. `verification.md` — daftar pemeriksaan sebelum rilis.

## Ringkasan konsep
Website statis menggunakan HTML, CSS, dan JavaScript dengan katalog, pencarian/filter, keranjang, jumlah barang, subtotal, total belanja, dan opsi membuat draf pesanan WhatsApp.

Website ini tidak otomatis memiliki akun, database, stok real-time, pembayaran online, atau riwayat transaksi. Nama toko, nomor WhatsApp, alamat, jam buka, katalog, harga, foto, dan kebijakan transaksi harus diganti dengan data yang benar sebelum dipublikasikan.

`verification.md` adalah checklist yang harus dijalankan pada implementasi minimarket; dokumen ini tidak menyatakan bahwa website sudah dibuat atau lulus pengujian.
